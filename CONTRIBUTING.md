# Як долучитися

Підручник відкритий для спільної роботи: можна виправляти помилки **і** пропонувати нові розділи, симулятори, пояснення. Сайт збирається з гілки `main` (GitHub Pages) — тому в `main` напряму не пушимо.

## Що можна пропонувати

- Виправлення формул, формулювань, багів у симуляторах
- Доповнення до вже наявних тем (приклади, кроки, підказки)
- Нові сторінки / розділи в тому ж стилі (коротка теорія + інтерактив)
- Покращення доступності, мобільного вигляду, навігації

Ідею великої нової теми зручно спочатку коротко описати в Issue — щоб узгодити місце в меню й обсяг.

## Короткі правила

1. Зроби гілку від актуального `main` (наприклад `fix/det2-focus`, `feat/rank-intro`).
2. Тримайся однієї задачі на PR. Не переписуй сусідні сторінки «заодно».
3. Перед PR відкрий сторінку локально і перевір інтерактив (кліки, формули, введення чисел).
4. У PR напиши 2–3 речення: **що** змінилось / додалось і **навіщо**.
5. Дочекайся review — merge робить maintainer після перегляду.

## Локально

Файли — звичайний HTML. Достатньо відкрити папку через локальний сервер, наприклад:

```bash
python3 -m http.server 8877
```

Далі: `http://127.0.0.1:8877/`

## Чого уникати

- Force-push і переписування історії на `main`
- Великі PR «на все відразу» — краще кілька маленьких
- Ламати позначення й знаки в поясненнях заради коротшого тексту

Питання й ідеї — через Issues.
